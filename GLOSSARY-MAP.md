# Glossary Map

## Contexts

- [Field survey](./teleferika.app/GLOSSARY.md): cable-crane / ropeway line planning and survey (also covers `licensed_features_package`, which shares this language)
- [Licensing](./licence_server/GLOSSARY.md): software licensing, device identity, approval, and feature gating — file created when the first licensing term is settled

## Relationships

- **Licensing → Field survey**: Licensing gates which Field survey capabilities are available in a build or on a device; it does not redefine Project, Point, or survey geometry terms
- **Field survey ↔ Licensing**: No shared domain types yet; keep vocabularies separate until a real cross-context concept appears
