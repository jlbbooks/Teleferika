# Obsidian vault — Teleferika

This folder is an **Obsidian** knowledge vault generated from the Teleferika monorepo.

## Open it

1. Install [Obsidian](https://obsidian.md/)
2. **Open folder as vault** → select this `obsidian-vault/` directory
3. Start at [[00 Home]]
4. Use **Graph view** to explore links (color groups configured for Overview / Domains / Concepts / …)

## Conventions

- Wiki-links: `[[Note Name]]`
- MOCs under `MOCs/`
- Frontmatter tags for filtering
- Detail that changes often still lives in upstream `README` / `doc/` files — see [[Documentation Index]]

## Keeping it fresh

Update vault notes when architecture, schema version, flavors, or module boundaries change. Prefer linking to in-repo docs for long how-tos rather than duplicating them verbatim.
