# Feature Registry

Plugin system (`feature_registry.dart`) that registers `FeaturePlugin` implementations and gates widgets/functions/services by licence.

- Opensource: stub / no premium plugins
- Full: [[licensed_features_package]] registers export + map-download features

`FeatureType`: widget | function | service | data
