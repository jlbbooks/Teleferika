# Cable Crane Planning

Teleferika’s problem domain: planning **cable crane / ropeway lines** for log transport in forests (Italian: *teleferica*).

Surveyors capture a sequence of ground points (anchors, intermediate supports, landings). The app helps:

- Align the line with a planned [[Azimuth]]
- Estimate spans and [[Geometry|rope length / slope]]
- Attach [[Cable Types]] assumptions (skyline, mainline, etc.)
- Document with maps and photos
- Export to GIS/office tools ([[Export]])

Aligns vocabulary with forestry/desktop tools (e.g. SEILAPLAN) via cable presets.
