# Azimuth

**Project azimuth** = intended direction of the cable line, stored on [[Projects]] / [[ProjectModel]], interpreted in **true north**.

UI: moving/azimuth markers on the [[Map]] show this direction from the device location so the operator can walk the line into alignment.

When RTK provides magnetic variation, device heading is corrected to true → [[Magnetic Variation]].
