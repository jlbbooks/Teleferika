# Current Features

Field-relevant capabilities for ropeway / log-transport professionals (from `teleferika.app/doc/CURRENT_FEATURES_README.md`).

1. **GPS point collection** — lat/lon/alt, accuracy, timestamps; ordered & editable → [[Points]]
2. **Compass & azimuth** — project azimuth; moving marker from device location → [[Azimuth]]
3. **Bearing, distance, rope length** — geometry + project model → [[Geometry]]
4. **Altitude & slope** — angle-at-point; angle-based polyline coloring
5. **Map backgrounds** — OpenTopo, Thunderforest, Esri topo/satellite, Carto → [[Map Types]]
6. **Offline operation** — tile caching; bulk download in full flavor → [[Export]] / map download
7. **Cable / equipment type** — project-level; seeded [[Cable Types]] table
8. **Project organization** — one project ≈ one line → [[Projects]]
9. **Marker slide** — long-press drag to fine-tune coordinates
10. **Photos at points** → [[ImageModel]]
11. **Line visualization** — polylines, arrowheads, slope colors → [[Map]]
12. **Data export** (licensed) → [[Export]]
13. **Location accuracy feedback** — accuracy circle; RTK fix quality colors
14. **Send feedback** — Settings form opens device mail to `info@jlbbooks.it` → [[Feedback]]
