# Field Survey Workflow

Typical operator flow:

1. Create / open a [[Projects|project]]; set [[Azimuth]] and optional [[Cable Types]]
2. Prefetch [[Map Types|map]] tiles if offline expected ([[Export|map download]] in full)
3. (Optional) Connect [[BLE RTK]] + configure [[NTRIP]]; wait for good fix quality
4. Walk the line; place [[Points]] from GPS/RTK; attach photos/notes
5. Review polyline, slope colors ([[Geometry]]), profile charts
6. Fine-tune with marker slide
7. (Full) [[Export]] for office / GIS / permits
